Nexora Knowledge Assistant

Production RAG system on AWS

A RAG assistant over company documents that answers with citations, using only the documents each user's role is allowed to see.

  • Hybrid retrieval (dense + BM25 + Reciprocal Rank Fusion) with cross-encoder reranking.
  • Profiled the pipeline stage by stage, found reranking took 78% of latency, and cut it with no quality loss; role-aware Redis answer cache.
  • Role-based access control inside vector search (JWT, 5 roles), PII masking, prompt-injection and output guardrails, checked with 28 integration tests and a 29-case red-team suite.
  • GitHub Actions CI (230 tests, 84% coverage) → Docker images to ECR → EC2 via SSM with automatic health-check rollback. Prometheus, Grafana and LangSmith for monitoring.
