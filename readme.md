# Abubakar Saddique — Portfolio

Personal portfolio of Abubakar Saddique, AI Engineer (Production RAG · AI Agents · LLMOps), Lahore, Pakistan.

**Live:** https://abubakarsaddique22.github.io/portfolio_datascience/

Plain HTML, CSS and JavaScript — no build step. Deploys straight to GitHub Pages from the `main` branch.

## Structure

```
index.html            page content
style.css             styles (dark theme, responsive)
script.js             nav, scroll reveal, typing text, hero network animation
images/about-me.png   profile photo
images/og-cover.png   link preview image (LinkedIn, WhatsApp, etc.)
cv/                   resume PDF
```

## Updating

- Projects, experience and skills are all in `index.html`.
- To replace the resume, keep the same file name: `cv/Abubakar_Saddique_AI_Resume.pdf`.
